How to update the website

  1. Add a new car, or Delete a car that is sold. Changes save on this device as you go.
  2. When you are finished, press Publish website at the bottom. A file downloads.
  3. Open that downloaded file (it unzips into a folder), then drag the folder onto app.netlify.com/drop. The website updates in about a minute.
